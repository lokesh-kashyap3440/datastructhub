# DataStructHub

> Interactive Data Structures Visualizer — animated, sound-enabled, and built for learning.

![DataStructHub](https://img.shields.io/badge/status-live-brightgreen) ![GitHub repo size](https://img.shields.io/github/repo-size/lokesh-kashyap3440/datastructhub) ![Vercel](https://img.shields.io/badge/deployed-vercel-black)

## ✨ Features

- 🎨 **8 Data Structures** — Array, Linked List, Stack, Queue, BST, Hash Table, Graph, Heap
- ⚡ **Animations** — Smooth, step-by-step visualizations using Anime.js
- 🔊 **Sound Effects** — Synthesized audio feedback via Web Audio API (no files needed)
- 📊 **Complexity Charts** — Live time complexity comparisons with Chart.js
- 🎛️ **Speed Control** — Adjust animation speed from 0.5x to 3x
- 📋 **Operation Log** — Timestamped history of every action
- 🌈 **Color-Coded** — Each structure has its own signature color
- 📱 **Responsive** — Works on desktop and tablet

## 🚀 Quick Start

### Local
```bash
# Serve locally
node server.js
# Open http://localhost:3000
```

### Android (same WiFi)
```
http://YOUR_PC_IP:3000
```

## 🚢 Deploy to Vercel

```bash
npm i -g vercel
vercel --prod
```

Or connect your GitHub repo at [vercel.com](https://vercel.com) for auto-deploys.

## 🛠️ Tech Stack

- **Pure HTML/CSS/JS** — No build step, no framework
- **Anime.js** — Smooth animations
- **Chart.js** — Complexity bar charts
- **Web Audio API** — Synthesized sounds
- **Google Fonts** — JetBrains Mono + Space Grotesk

## 📖 How to Use

1. Select a data structure from the sidebar
2. Enter a value and choose an operation
3. Click **Execute** to see it in action
4. Use **Random** to generate test data
5. Watch the chart update with operation complexity
